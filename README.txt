# 전기차량 주차 확인 관리 프로그램

## 기능
- 차량번호 + 차종 등록
- 등록 차량 수량 표시
- 오늘 등록 차량 수 표시
- 등록된 차량 목록에서 개별 삭제
- 전체 삭제
- 브라우저를 닫아도 데이터 유지(localStorage)
- 카카오톡 공유 버튼
  - 휴대폰: 운영체제 공유창을 열어 카카오톡을 선택할 수 있음
  - PC/공유 기능 미지원 환경: 전체 차량 정보를 클립보드에 복사하여 카카오톡에 붙여넣기

## 실행
`index.html`을 크롬/엣지에서 열면 됩니다.

## 중요
현재 버전은 별도의 서버나 회원로그인이 없는 현장용 단일 웹페이지입니다.
따라서 입력 데이터는 사용 중인 기기의 해당 브라우저에만 저장됩니다.

'카카오톡으로 바로 보내기'를 카카오톡 SDK의 전용 공유창으로 구현하려면
카카오 개발자 앱의 JavaScript 키와 웹 도메인 등록이 추가로 필요합니다.


## 카카오톡 실제 친구/채팅방 공유 설정

이번 버전은 카카오 JavaScript SDK 2.8.1의 `Kakao.Share.sendDefault()`를 사용합니다.
공유 버튼을 누르면 카카오톡의 친구/채팅방 선택 화면이 열리고, 사용자가 대상을 선택해 차량 목록을 전송합니다.

### 1. 카카오디벨로퍼스 앱 만들기
- Kakao Developers에서 애플리케이션을 생성합니다.
- 앱의 JavaScript 키를 확인합니다.
- 이 프로그램의 '카카오톡 공유 설정'에 JavaScript 키를 입력합니다.

### 2. 웹 도메인 등록
- 현재 프로그램을 단순히 `file://`로 실행하는 것만으로는 실제 카카오톡 공유가 정상 작동하지 않을 수 있습니다.
- 실제 사용할 웹주소(예: https://example.com)를 카카오디벨로퍼스의 JavaScript SDK 도메인/제품 링크에 등록해야 합니다.
- 따라서 실제 운영 시에는 웹서버 또는 HTTPS 호스팅에 올리는 것을 권장합니다.

### 3. 친구/채팅방 선택
`pickerSettings.type: "default"`로 설정되어 있어 카카오톡 공유 대상에서 친구와 채팅방을 선택할 수 있습니다.
카카오 공식 문서 기준으로 기본 공유 대상 선택 화면에는 친구와 채팅방이 함께 표시됩니다.

### 주의
이 프로그램에서 카카오 JavaScript 키를 제가 임의로 만들어 넣을 수는 없습니다.
카카오에서 발급되는 실제 키가 필요합니다.


## 사진으로 차량번호 인식 기능

- 휴대폰에서 `차량 사진 선택 / 촬영`을 누르면 카메라 촬영 또는 사진 선택이 가능합니다.
- Tesseract.js OCR로 사진 속 한국어/영문 문자를 인식합니다.
- 인식된 차량번호를 자동으로 입력창에 넣습니다.
- 사용자가 번호를 확인/수정한 후 `인식된 차량 등록`을 누릅니다.
- 차종은 사진만으로 정확히 판별하기 어려우므로 직접 입력하도록 했습니다.
- OCR은 사진 품질에 따라 오인식할 수 있으므로 번호 확인 절차가 필요합니다.
- OCR 라이브러리는 CDN에서 처음 불러오므로 인터넷 연결이 필요합니다.

### 정확도를 높이는 촬영 방법
1. 번호판이 화면에서 크게 보이도록 촬영
2. 흔들리지 않게 촬영
3. 어두운 지하주차장에서는 플래시/조명을 활용
4. 번호판이 반사되어 번지지 않도록 정면에 가깝게 촬영
