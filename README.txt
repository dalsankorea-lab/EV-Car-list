# 전기차량 주차 확인 관리 프로그램

## 기능
- 차량번호 + 차종 등록
- 등록 차량 수량 표시
- 오늘 등록 차량 수 표시
- 등록된 차량 목록에서 개별 삭제
- 전체 삭제
- 브라우저를 닫아도 데이터 유지(localStorage)
- 카카오톡 공유 버튼
  - 휴대폰: 운영체제 공유창을 열어 카카오톡을 선택할 수 있음
  - PC/공유 기능 미지원 환경: 전체 차량 정보를 클립보드에 복사하여 카카오톡에 붙여넣기

## 실행
`index.html`을 크롬/엣지에서 열면 됩니다.

## 중요
현재 버전은 별도의 서버나 회원로그인이 없는 현장용 단일 웹페이지입니다.
따라서 입력 데이터는 사용 중인 기기의 해당 브라우저에만 저장됩니다.

'카카오톡으로 바로 보내기'를 카카오톡 SDK의 전용 공유창으로 구현하려면
카카오 개발자 앱의 JavaScript 키와 웹 도메인 등록이 추가로 필요합니다.
